# Snapshot de Tarefas apos o seletor de workspace

## Escopo

Esta fatia comeca sobre `main` somente depois da integracao da fatia 07.
A troca das tabs pelo seletor nativo altera pixels compartilhados do shell desktop exibido em `/tarefas`, embora a fatia 07 possua somente os baselines do shell.
O oraculo existente em `tarefas.spec.ts` ja captura Lista em 1440x900 como `tarefas-desktop.png` e Kanban em 390x844 como `tarefas-mobile.png`.
Portanto, esta fatia possui somente o baseline desktop e nao altera teste ou codigo de produto.

## Red

1. Registrar o checksum SHA-256 de `tarefas-mobile.png` antes de qualquer atualizacao.
2. Rodar o oraculo visual existente sem update de snapshots.
3. Confirmar o FAIL deterministico apenas na comparacao de `tarefas-desktop.png`, causado pelos pixels do novo seletor.
4. Falhar a fatia se houver erro funcional, diferenca mobile ou qualquer causa alem do baseline desktop obsoleto.

```bash
shasum -a 256 tests/e2e/__screenshots__/tarefas.spec.ts/tarefas-mobile.png
npm run test:e2e -- tests/e2e/tarefas.spec.ts --project=chromium --grep "mantém Tarefas legível em desktop e mobile"
```

## Green

1. Rodar o mesmo oraculo uma unica vez com `--update-snapshots`.
2. Confirmar imediatamente que somente `tarefas-desktop.png` aparece no diff.
3. Confirmar com `sips` que o baseline regenerado mede exatamente 1440x900.
4. Inspecionar o PNG desktop em tamanho original, verificando seletor, hierarquia, alinhamento, foco visivel, contraste, quebras, acoes e ausencia de clipping ou overflow.
5. Comparar o checksum mobile com o valor registrado no Red e exigir igualdade.
6. Falhar se `tarefas-mobile.png`, `tarefas.spec.ts` ou qualquer outro arquivo mudar.

```bash
npm run test:e2e -- tests/e2e/tarefas.spec.ts --project=chromium --grep "mantém Tarefas legível em desktop e mobile" --update-snapshots
git status --short -- tests/e2e/__screenshots__/tarefas.spec.ts
sips -g pixelWidth -g pixelHeight tests/e2e/__screenshots__/tarefas.spec.ts/tarefas-desktop.png
shasum -a 256 tests/e2e/__screenshots__/tarefas.spec.ts/tarefas-mobile.png
git diff --exit-code -- tests/e2e/__screenshots__/tarefas.spec.ts/tarefas-mobile.png
```

## Refactor

Nao ha refactor de codigo nesta fatia.
Depois da inspecao visual, repetir o oraculo sem update e revisar o diff para garantir ownership estrito.
